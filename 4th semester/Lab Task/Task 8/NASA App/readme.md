# NASA App (Flask)

Simple Flask app that uses NASA's public APIs to show the Astronomy Picture of the Day (APOD) and recent Mars Rover photos.

Quick start

1. (Optional) create a Python virtual environment and activate it.

2. Install dependencies:

```powershell
python -m pip install -r requirnments.txt
```

3. (Optional) set your NASA API key. If you don't, the app will use NASA's `DEMO_KEY`.

```powershell

```

4. Run the app:

```powershell
python app.py
```

Open http://localhost:5000 in your browser.

Notes
- The demo key is rate-limited. For production or higher usage, obtain a free API key at https://api.nasa.gov/ and set `NASA_API_KEY`.
- This project is intended as a small demo and learning exercise.
